# 💰 Budget App UI/UX Design

A modern and minimal **UI/UX design for a Budget Management Application**, created using **Figma**.  
This design helps users efficiently track their income, expenses, and overall financial health with a clean and intuitive interface.

---

## 📌 Project Overview

The **Budget App UI/UX** is designed to provide a seamless user experience for managing personal finances.  
It allows users to:
- View **current balance** and **monthly budget progress**.
- Track **recent transactions**.
- Add new **income** or **expense** entries.
- Analyze **spending trends** and **top categories** over time.

---

## 🎨 Design Details

- **Tool Used:** Figma  
- **Project Type:** UI/UX Design  
- **Platform:** Desktop & Mobile Friendly  
- **Design Features:**
  - Dashboard with Current Balance and Budget Summary
  - Transaction List (Income & Expenses)
  - Add Transaction Modal
  - Spending Analysis Charts (Weekly, Monthly, Yearly Views)
  - Category Breakdown (Food, Rent, Bills, etc.)
